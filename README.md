# threat-research-lab
Adversary technique implementation &amp; detection analysis for malware analysis and threat intelligence research.
## maldev

공격 기법의 직접 구현과 탐지 분석을 통한 MA/CTI/DFIR 역량 강화 레포지토리.

Disclaimer: 이 레포지토리는 교육 및 보안 연구 목적으로만 사용됩니다. 문서화된 모든 기법은 이미 공개된 기술이며, 각 구현에는 방어자가 해당 행위를 탐지할 수 있도록 탐지 가이드를 포함합니다.

목적

공격 기법을 코드 레벨에서 이해하는 것은 악성코드 분석과 위협 인텔리전스의 기본이다. 이 레포지토리는 공격 기법을 C/ASM으로 직접 구현하고, 각 기법이 메모리에서 어떻게 보이는지, 어떤 흔적을 남기는지, 어떻게 탐지할 수 있는지를 함께 정리한다.
